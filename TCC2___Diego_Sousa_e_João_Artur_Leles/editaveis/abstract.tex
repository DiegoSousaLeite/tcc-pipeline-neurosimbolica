\begin{resumo}[Abstract]
 \begin{otherlanguage*}{english}
    This work investigates the use of Large Language Models (LLMs) to reduce the false positives of Static Application Security Testing (SAST) tools in code written in the Go language. The study starts from the problem of alert fatigue, in which the excess of false alarms leads development teams to distrust these tools and to ignore their results. The objective is to evaluate a hybrid symbolic-neural architecture, in which the Semgrep static analyzer points out potential problems and an LLM decides, based on the code of each alert, which of them are real vulnerabilities. To this end, a controlled experiment was conducted on 2,328 cases from real projects, with two local models and one commercial model and with two types of prompt, one without guidance and an expert one, enriched with the definition of the weakness, language heuristics, and examples. The results show that the model works as a filter, reducing the number of alerts to be reviewed by more than 98\% with the best local model, but it also discards most of the real vulnerabilities. The effect of the expert prompt varied with the model, and even the best configuration missed about half of the vulnerabilities that the analyzer did not detect. The investigation of the analyzer's low detection also showed that part of the problem lies in how vulnerability databases label the cases. The study contributes an evaluation that measures both the reduction of alerts and the vulnerabilities lost, makes the pipeline and data available for future research, and indicates that the model would be more useful before the analyzer, helping to generate rules, than after it, merely filtering alerts.

   \vspace{\onelineskip}
 
   \noindent 
   \textbf{Keywords}: static analysis; Go language; artificial intelligence; automated triage; hybrid symbolic-neural architecture; software security.
 \end{otherlanguage*}
\end{resumo}
